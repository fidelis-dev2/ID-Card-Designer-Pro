# ID Card Designer Pro - Front & Back

Features:
- Design upande wa mbele na nyuma.
- Geuza Mbele/Nyuma.
- Drag, resize, rotate, edit text and appearance.
- Upload image/logo/passport.
- Camera support on localhost/HTTPS.
- QR Code and Barcode.
- Save/Load JSON for both sides.
- Export current side as PNG.
- Export/Print both sides as PDF.
- User manual: manual.html.
- Playable browser guide: video-guide.html.

Open `index.html` in browser. For camera, use localhost or HTTPS.
